# TrustAudit — Cryptographic Evidence & Verification Specification

## 1. Cryptographic Design Goals

The Cryptographic Evidence Engine fulfills three core objectives:
1. **Mathematical Tamper-Evidence**: Enable anyone with authorized access to the private record to prove whether off-chain data has been altered after registration.
2. **Confidentiality & Anti-Preimage Defense**: Prevent external observers from guessing transaction contents via rainbow tables or brute-force dictionary attacks.
3. **Deterministic Canonicalization**: Guarantee that identical logical datasets always produce identical cryptographic commitments, independent of programming language or JSON key ordering.

---

## 2. Canonical Serialization (RFC 8785 — JSON Canonicalization Scheme)

Standard `json.dumps()` in Python, `JSON.stringify()` in JavaScript, or formatting in database query tools can vary in key order, whitespace, and number representations. TrustAudit strictly adheres to **RFC 8785 (JCS)**:
- Keys are sorted lexicographically by UTF-16 code units.
- Whitespace between separators is strictly eliminated (no spaces after `:` or `,`).
- UTF-8 character encoding without Byte Order Mark (BOM).
- Numbers are formatted without unnecessary trailing zeros or exponent notation where forbidden.

## 3. Commitment Construction & Domain Separation

### 3.1 Domain-Separated Hash Formula
To prevent cross-protocol collision attacks, the commitment incorporates a protocol domain prefix, the canonical JSON payload, and a 32-byte secret salt:

$$\text{saltedInputHash} = \text{SHA256}\Big(\text{"TrustAudit:v1"} \parallel \text{JCS}(\text{TransactionData}) \parallel \text{salt}\Big)$$

Where:
- `"TrustAudit:v1"`: 13-byte ASCII domain separation tag.
- `JCS(TransactionData)`: UTF-8 encoded canonical JSON bytes.
- `salt`: 32 raw bytes generated by a cryptographically secure pseudorandom number generator (`secrets.token_bytes(32)`).
- $\parallel$: Byte-level concatenation.

### 3.2 Commitments Breakdown

| Commitment Name | Input Source | Construction Formula | Stored On-Chain |
| :--- | :--- | :--- | :---: |
| **`caseId`** | Global unique identifier | `bytes32(keccak256(abi.encodePacked(uuid4_bytes)))` | Yes |
| **`saltedInputHash`** | Private transaction data | `SHA256("TrustAudit:v1" || JCS(privateData) || salt)` | Yes |
| **`explanationHash`** | Local SHAP report | `SHA256("TrustAudit:XAI:v1" || JCS(topFeatures))` | Yes |
| **`commentHash`** | Written review justification | `SHA256("TrustAudit:Comment:v1" || UTF8(justificationText))` | Yes |

## 4. Integrity Verification Algorithm

```mermaid
flowchart TD
    A[Auditor Requests Verification for caseId] --> B[Retrieve Stored Private Record & Secret Salt from Database]
    B --> C{Salt or Record Missing?}
    C -- Yes --> D[Result: CORRUPT_EVIDENCE / MISSING_DATA]
    C -- No --> E[Reconstruct Canonical JSON via RFC 8785]
    E --> F[Compute Hash: SHA256 'TrustAudit:v1' || JCS || salt]
    F --> G[Fetch on-chain saltedInputHash from TrustAuditRegistry.sol]
    G --> H{Recomputed Hash == On-Chain Hash?}
    H -- Identical --> I[Result: INTEGRITY_VERIFIED ✅]
    H -- Mismatch --> J[Result: TAMPERING_DETECTED 🚨]
    J --> K[Run Field-by-Field Differential Diagnostic]
    K --> L[Highlight Altered Fields e.g. amount changed 60000 -> 6000]
```

## 5. Reference Python Implementation & Test Vectors

```python
import hashlib
import json
import secrets

def canonicalize_json(data: dict) -> bytes:
    """RFC 8785 compliant canonical JSON serialization."""
    return json.dumps(
        data,
        ensure_ascii=False,
        sort_keys=True,
        separators=(',', ':')
    ).encode('utf-8')

def generate_salt() -> bytes:
    """Generate 32-byte CSPRNG salt."""
    return secrets.token_bytes(32)

def compute_salted_input_hash(data: dict, salt: bytes) -> str:
    """Compute domain-separated salted commitment."""
    assert len(salt) == 32, "Salt must be strictly 32 bytes"
    prefix = b"TrustAudit:v1"
    payload = canonicalize_json(data)
    hasher = hashlib.sha256()
    hasher.update(prefix)
    hasher.update(payload)
    hasher.update(salt)
    return "0x" + hasher.hexdigest()
```
